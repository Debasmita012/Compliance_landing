# Compliance Landing Page – Figma to HTML/CSS

A modern, responsive landing page developed by converting a Figma UI design into a static website using HTML, CSS and JavaScript. The project focuses on accurate design implementation, responsive layouts, clean code structure and interactive UI elements.

## 🌐 Live Demo

**Live Website:** [https://fig-zeta-seven.vercel.app/]

## 📌 Project Overview

The objective of this project is to recreate a professional compliance-focused landing page based on the provided Figma design, maintaining visual consistency across desktop, tablet and mobile devices.

The website presents compliance services for research analysts through a clean interface, structured content sections, illustrations, feature cards and interactive navigation elements.

## ✨ Features

- **Responsive Design:** Optimized layouts for desktop (1440px), tablet (768px) and mobile (375px).
- **Navigation Bar:** Responsive navigation with desktop links and mobile/tablet slide-out menus.
- **Hero Section:** Attractive introduction with headline, supporting content, illustrations and call-to-action buttons.
- **Compliance Benefits:** Dedicated section explaining the importance of compliance for research analysts.
- **Feature Cards:** Highlights Regulatory Clarity, Hassle-Free Filings and Risk Protection.
- **Hover Effects:** Interactive button states and feature card hover animations.
- **Responsive Typography:** Uses Roboto typography with appropriate font sizes, weights and line heights for different screen sizes.
- **Clean UI:** Consistent spacing, colors, alignment and visual hierarchy.

## 📱 Responsive Breakpoints

The website is designed to adapt to different screen sizes.

| Device | Reference Width |
|---|---:|
| Desktop | 1440px |
| Tablet | 768px |
| Mobile | 375px |

The layout adjusts its navigation, typography, content alignment, images and feature cards according to the available screen width.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd compliance-landing
```

**3. Run the website**

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code.

No additional package installation or build process is required.
